# 外部插件接入

目标是让其它插件的 WebUI 以卡片形式出现在面板上，点击即跳转，需要令牌的自动带上。

## 接入步骤

1. 编辑 `plugins.json`，在 `plugins` 数组里加一项。
2. 重启面板。
3. 卡片出现在面板「插件入口」区；点击按配置拼出地址并新标签打开。

不改代码。

## 字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 是 | 唯一标识，小写字母开头，可含数字与下划线 |
| `name` | 是 | 卡片标题 |
| `desc` | 否 | 一句话说明 |
| `port` | 是 | 宿主端口。面板只连 `127.0.0.1` |
| `path` | 否 | URL 路径，默认 `/` |
| `container` | 否 | 所属容器名。声明后容器未运行则卡片置灰 |
| `tokenFile` | 否 | 容器内令牌文件路径，后端即时读取，不落盘、不进前端 |
| `tokenQuery` | 否 | 令牌 query 参数名，默认 `token` |
| `tokenHeader` | 否 | 预留字段，当前版本只记录不发送 |

## 示例

### 无令牌的插件

```json
{
  "id": "my_plugin",
  "name": "我的插件",
  "desc": "本地小工具",
  "port": 19500,
  "path": "/"
}
```

### 需要令牌、且依赖某个容器

```json
{
  "id": "my_plugin",
  "name": "我的插件",
  "desc": "容器内服务",
  "port": 19500,
  "path": "/console",
  "container": "fish-bot",
  "tokenFile": "/data/plugins/my_plugin-token",
  "tokenQuery": "token"
}
```

点击后拼成：`http://127.0.0.1:19500/console?token=<从容器读取>`

## 安全约束

- **只允许 127.0.0.1**：端口是整数，主机写死，配置里无法填外部域名，因此面板不会变成任意 URL 跳转器。
- **令牌不写入配置文件**：`plugins.json` 可以进版本库；令牌放在容器内文件里，由后端每次点击时即时读取。
- **id 必须在注册表里**：`/api/consoles/<id>/open` 只解析登记过的 id，未登记的返回 409。
- **令牌不进日志**：与主面板的其它入口一致，只回传地址，不写日志、不缓存。

## 行为说明

| 情况 | 表现 |
| --- | --- |
| 端口未监听 | 仍返回地址，提示「页面可能需要先启动该服务」 |
| 声明的容器未运行 | 卡片置灰，点击返回 409 |
| 令牌文件读不到 | 返回不带令牌的地址，提示手动登录 |
| 配置解析失败 | 面板正常启动，插件区为空，日志记一行警告 |

## 当前限制

- 只支持 GET 跳转，不代理请求，不做 iframe 嵌入。
- 一个插件一个入口，不支持多页面嵌套。
- `tokenHeader` 尚未生效：需要请求头的场景要等后续版本，或让插件自身支持 query 参数。
