# 后续设计备忘

本次仅记录方向，不实施。面板中的「性格设置」「AI 记忆」区块只是布局预留。

## 人格

- 现有桥接已支持角色查询、编辑和切换。
- 当前角色选择是全局状态，一处切换影响所有会话。
- 将来要按会话独立选择人格，需要扩展桥接的角色接口。

## 记忆

- 当前迁移脚本会把所有历史会话记忆合入当前会话，存在跨私聊、跨群混入的风险。
- 后续应按包含机器人账号的稳定 QQ 会话标识隔离。
- 无法确认归属的历史记忆不得自动分配。
- 删除记录必须贯穿迁移与恢复，避免已删除内容复活。
- 需区分「清空聊天上下文」与「忘记长期记忆」两件事。
- 需修复只在启动后迁移一次的机制，以及并发写入问题。

## 心情

- 失效根因尚未确认。
- 后续依次检查：插件是否激活、会话是否绑定、消息来源是否真实、判断调用是否发生、下一轮是否注入。
- 不把推测直接当作修复依据。
